# Home-App-Project
# 🏠 Home Project Shopping List Generator

![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![Status](https://img.shields.io/badge/Status-Complete-brightgreen.svg)

A Python application that helps homeowners, renters, and DIY enthusiasts plan home improvement projects by generating shopping lists, estimating costs, and exporting project materials.

---

## 📖 Overview

The **Home Project Shopping List Generator** simplifies planning for home improvement projects. Instead of manually creating shopping lists, users can browse a catalog of projects, select one or more projects, and automatically generate a combined shopping list with estimated costs.

The application also supports custom materials, duplicate item merging, CSV/JSON exports, and quick search links to popular home improvement retailers.

---

## ✨ Features

* 📂 Browse a catalog of home improvement projects
* 🔍 Search projects by keyword or category
* ✅ Select multiple projects
* 🧰 Display required tools
* 🛒 Generate a combined shopping list
* 🔄 Automatically merge duplicate materials
* 💲 Calculate estimated total cost
* ➕ Add custom materials
* 📄 Export shopping lists to CSV
* 📄 Export shopping lists to JSON
* 🏪 Generate search links for:

  * Home Depot
  * Lowe's
  * Ace Hardware
  * Amazon

## 🚀 Getting Started

### Prerequisites

* Python 3.10 or newer

### Installation

Clone the repository:

```bash
git clone https://github.com/Mr-Tillis/Home-Project-App.git
```

Change to the project directory:

```bash
cd Home-Project-App
```

Run the application:

```bash
python main.py
```

---

## 🖥️ Example Workflow

1. Launch the application.
2. Browse the available home improvement projects.
3. Search for a project by keyword (optional).
4. Select one or more projects.
5. Add custom materials if needed.
6. Generate the shopping list.
7. Review required tools and estimated costs.
8. Export the shopping list as CSV or JSON.
